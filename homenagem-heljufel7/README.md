# Homenagem a Heljufel7

Um site moderno e vibrante feito em React + Vite para homenagear o jogador de League of Legends "Heljufel7".
O site exibe informações como dossiê de maestria, histórico de partidas, KDA e Elo (mockados), com tema focado no campeão principal (Ashe).

## Requisitos
- Node.js

## Como rodar

Dê um duplo clique no arquivo correspondente ao seu sistema operacional:
- **Windows**: `iniciar.bat`
- **macOS**: `iniciar.command`

O servidor será iniciado na porta **5173** e abrirá automaticamente no navegador.
Se preferir acessar manualmente, acesse: `http://localhost:5173`
